# P02｜乱序订单事件的幂等重放

difficulty: 3/5
deliverable: results/scheduled-model-20261025/P02.py
entrypoint: replay(events)

## 任务
实现 `replay(events: list[dict]) -> dict`。每条事件是字典：
- `event_id`: 全局非空字符串；
- `order_id`: 非空字符串；
- `revision`: 非负整数（bool 不算整数）；
- `kind`: "SET" 或 "DELETE"；
- 当 kind="SET" 时，必须有 `amount`，且为非负整数（允许0）；
- 当 kind="DELETE" 时，禁止出现 `amount` 字段（即便其值为 None 也不允许）。

事件**乱序**到达。先按全局 event_id 去重：完全相同事件仅重放一次；相同 event_id 的任意内容不同则 ValueError。同一 order_id 下，同一个 revision 只能存在一条不同 event_id 的事件；若存在两条，不论其 kind/amount 是否相同，均 ValueError。对每个订单按 revision 升序重放：SET 设置金额并激活，DELETE 删除并留下 tombstone；较高 revision 始终覆盖低版本，允许被删除的订单在更高 revision SET 后复活。

返回精确结构：
```python
{
 "active": [{"order_id":"...", "amount": 0, "revision": 0}, ...],
 "deleted": [{"order_id":"...", "revision": 0}, ...],
 "total_amount": 0
}
```
active/deleted 均按 order_id 升序；total_amount 为 active 中金额总和（Python 整数，无溢出截断）。空列表返回三个字段，列表为空且总额0。不得修改原始输入。

## 样例
```python
events=[
 {"event_id":"e1","order_id":"o1","revision":1,"kind":"SET","amount":50},
 {"event_id":"e2","order_id":"o1","revision":3,"kind":"DELETE"},
 {"event_id":"e3","order_id":"o1","revision":2,"kind":"SET","amount":70},
 {"event_id":"e4","order_id":"o2","revision":1,"kind":"SET","amount":20},
 {"event_id":"e4","order_id":"o2","revision":1,"kind":"SET","amount":20},
]
replay(events)
```
期望：
```python
{"active":[{"order_id":"o2","amount":20,"revision":1}],
 "deleted":[{"order_id":"o1","revision":3}],
 "total_amount":20}
```
invalid events 类型、不足字段、错误类型、冲突版本、冲突去重均抛 ValueError。目标时间复杂度 O(n log n)，额外空间 O(n)。
