# P01｜半开时间窗合并与幂等去重

difficulty: 2/5
deliverable: results/scheduled-model-20261025/P01.py
entrypoint: merge_windows(events, gap)

## 任务
实现 Python 函数 `merge_windows(events: list[dict], gap: int) -> list[dict]`。输入是多租户事件，每条形如：
`{"event_id":"e1","tenant":"x","start":0,"end":5}`。
时间窗是半开区间 `[start,end)`，start/end 可以为负整数；gap 为非负整数。

先按**全局 event_id** 做幂等去重：完全相同的事件重复出现只算一次；同一 event_id 若出现任一字段不同，抛出 ValueError。再按 tenant 分组，按照 (start,end,event_id) 升序扫描合并时间窗。如果下一窗 `start <= 当前合并窗口的 end + gap` 则并入（包含恰好相接），并更新 end 为两者最大值；否则另开一窗。输出每个合并后的记录 `{"tenant":str,"start":int,"end":int,"count":int}`，count 是被合并的不同 event_id 数量。结果按 (tenant,start,end) 字典序升序。

## 必须校验
events 必须为 list，事件必须是包含上述四个字段的 dict；event_id、tenant 必须是非空字符串；start、end 必须为真正的整数（bool 不算整数），且 start < end；gap 必须为非负整数（bool 不算整数）。非法输入抛 ValueError。不要修改输入对象。

## 例子
输入：
```python
events=[
 {"event_id":"e1","tenant":"x","start":0,"end":5},
 {"event_id":"e2","tenant":"x","start":7,"end":9},
 {"event_id":"e3","tenant":"x","start":9,"end":10},
 {"event_id":"e4","tenant":"y","start":1,"end":3},
 {"event_id":"e2","tenant":"x","start":7,"end":9},
]
merge_windows(events,2)
```
输出：
```python
[
 {"tenant":"x","start":0,"end":10,"count":3},
 {"tenant":"y","start":1,"end":3,"count":1},
]
```
空事件列表返回 []。目标时间复杂度 O(n log n)；额外空间 O(n)（不计输出）。
