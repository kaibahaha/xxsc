## 任务
实现 `reconcile_versions(events: list[dict]) -> list[dict]`，用于处理异步多副本的版本冲突。每条事件：
```python
{"event_id":"u1","key":"k","clock":{"A":1},"value":"a","timestamp":10}
```
event_id 和 key 为非空字符串；clock 为 dict，键为非空字符串（节点名称），值为非负整数（拒绝 bool）；clock 可以为空，缺失的节点计数视为0；value 必须是字符串或 None（None 代表墓碑删除）；timestamp 为非负整数（拒绝 bool）。

全局 event_id 完全相同的事件做幂等去重；同 ID 但任一字段不同即 ValueError。不同 key 之间独立处理。对同一 key 的两条不同事件 x,y，若对于所有节点 `clock(x)[node] >= clock(y)[node]` 且至少一个节点严格大于，那么 x **严格因果支配** y，y 为 superseded。若两者所有节点计数相等，则**都不支配对方**。同样，并发互不支配。

找出每个 key 下**没有被任何其他事件严格支配的极大版本集合** maxima；其他均视作 superseded。若 maxima 有多个，即冲突；在 maxima 内以 `(timestamp, event_id)` 降序取最大者作为确定性 winner，timestamp 不参与因果支配。每个 key 返回：
```python
{
 "key":"k",
 "winner_id":"u2",
 "value":"b",
 "conflict_ids":["u2","u3"],
 "superseded_ids":["u1"]
}
```
- `conflict_ids`：如果 maxima 多于一个，则包含所有 maxima 的 event_id，按字典序升序；否则返回 []（不要把唯一 winner 放进去）。
- `superseded_ids`：被任意事件严格因果支配的所有 event_id，升序。
- 输出按 key 升序；空列表返回 []；不得修改输入。
- 事件去重后，两个不同 ID、相同 clock 的版本并存为冲突，不允许私自合并。

## 样例
```python
events=[
 {"event_id":"u1","key":"k","clock":{"A":1},"value":"a","timestamp":10},
 {"event_id":"u2","key":"k","clock":{"B":1},"value":"b","timestamp":11},
 {"event_id":"u3","key":"k","clock":{"A":2},"value":"c","timestamp":9},
 {"event_id":"u4","key":"z","clock":{"A":1,"B":1},"value":None,"timestamp":3}
]
reconcile_versions(events)
```
期望：
```python
[
 {"key":"k","winner_id":"u2","value":"b","conflict_ids":["u2","u3"],"superseded_ids":["u1"]},
 {"key":"z","winner_id":"u4","value":None,"conflict_ids":[],"superseded_ids":[]}
]
```
边界：equal clocks、隐含0、全并发、严格偏序链、值为 None、重复 ID 冲突、timestamp 相同按 event_id 比较、空 clock。错误输入一律 ValueError。允许每 key O(m²×k) 的两两比较（m=该 key 版本数，k=节点数）。
