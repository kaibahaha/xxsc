# V1.2.1 机器合同留存说明

此目录包含从 **第二卷 V1.2.1 §21** 原文直接解析导出的 7 份 `*.schema.json`、7 份 `*.valid.json` 和 `extraction_manifest.json`。JSON 结构未因 V1.3 架构精简而改动；缩进可能不同，但 JSON 语义与原文一致。

**本目录绝不代表**：V1.3 已修改/批准 Schema、它们已部署 GitHub、Controller 已支持全部字段、V1.3 与 V1.2.1 活跃数据可随意混写。

用途：既有历史机器资产的检索、迁移前差异评审、回归验证和审计。未来若用户批准 V1.3 运行，应在独立测试环境明确决定是否仍启用这七类正式消息对象；如决定简化，应有明示的版本与迁移机制，不在现有事件流静默删除/改名字段。

**日常 Agent 不需要打开这些 JSON 全文**，只有执行相关格式校验、写高风险状态对象或进行版本迁移时才按需读取。
