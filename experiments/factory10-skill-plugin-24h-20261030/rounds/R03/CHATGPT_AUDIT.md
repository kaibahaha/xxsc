## 2. ChatGPT独立交叉核验（事实与边界）

4. **itch.io分成：确认**。官方 `https://itch.io/docs/creators/payments` 说明0–100%开放分成、默认10%，支付处理费通常约$0.30+2.9%；但地区、支付模式、税务和处理费均可能变化，不能把它简化成固定净收入公式。
5. **WorkBuddy本机插件状态：未独立复现**。报告列 `codebuddy plugin list` 0插件、`codebuddy mcp list` 0服务器、官方市场209项及版本2.177.0，均是有命令片段的SELF_REPORTED，不能推出ChatGPT当前插件或MCP的状态。
6. **内置工具可用性：应降级描述**。ImageGen、VideoGen、Artifact、CronCreate、LSP“schema可读”证明候选接口在WorkBuddy上下文可发现，**不等于已成功执行、拥有授权、可免费商用或保证输出格式**。积分价格只能记为WorkBuddy自述工具schema，未经独立价格核验。

8. **模拟科学有效性与游戏确定性不同**。同种子SHA一致只证明计算重放，不能证明泊松参数、信号/本底分布或IceCube探测器物理真实性；需独立统计校准和物理专家/官方数据验证。报告从v1零检出改为v2检出14是可疑的调参依据，需预先冻结参数与目标、独立检验误报/漏报，避免为“好看结果”改模型。

## 3. P0/P1缺陷及可验收整改
- **P0-1：实际执行证据未闭环**。补交 `icecube_sim.py` 完整源代码、固定输入 `SIM_SPEC.md`、`SEED_FIXTURES.json`、`REPLAY_CHECK.md`、3次原始命令/exit code/stdout、环境版本和SHA；使用隔离测试环境重放并验证所有输出哈希。没有文件就不得将“第三方可复现”标PASS。
- **P0-2：事件完整性与真实性混淆**。哈希差异只是完整性检测手段，若攻击者能同时修改日志和哈希则无法发现；要求 `manifest` 中记录可信签名或由只追加存储/独立审计者签署；增加“日志+哈希同时被篡改”负例，验收必须阻断。
- **P1-3：模拟科学校准不足**。区分“教学游戏中的玩具泊松模型”与“真实IceCube物理模拟”，公开参数来源、固定分布假设、统计检验、误报率与敏感性分析，禁止将教学模拟输出称为真实探测概率。
- **P1-4：单文件网页与多文件构建冲突**。案例B承诺Artifact单HTML，但输出 `sim_core.js` 和 `test_state.js`；若目标单文件，明确将核心JS内联或打包，保留源码和构建步骤；无浏览器时可先Node验证纯逻辑，但不能称“可玩性已验收”。
- **P1-5：发布与商业成本仍需实证**。对ImageGen/VideoGen credits、各渠道账号/分成/地区限制、插件实际权限逐项以当时官方账单或账号授权证据核实；未核实标UNKNOWN。微信小游戏含 `npx @latest` 供应链风险，应锁版本和哈希，独立审批。
- **P1-6：安全边界细化**。报告正确指出worktree非沙箱、插件可执行代码；但“沙箱是唯一OS级手段”表述过绝对，容器/VM、用户权限、MAC等也可形成OS级边界。安全方案应以系统权限和负例测试证明，而非单凭文档或工具名称。
