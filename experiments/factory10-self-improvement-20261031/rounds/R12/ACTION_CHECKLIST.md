## P2-01 GitHub Copilot Free（B条件候选）
官方 https://docs.github.com/en/copilot/how-tos/manage-your-account/get-started-with-a-copilot-plan ；价值：$0有限补全和AI credits，可用于F2日常辅助；预计3–5分钟只读核验。步骤：用户自己登录GitHub→Settings/Billing & licensing/Copilot查看当前套餐与是否有组织席位→记录非敏感套餐名称、免费额度与当前限制→若符合再由用户决定启用。不得为免费权益取消既有付费计划；无自动代操作。资格UNKNOWN；截止：持续入口，未查到明确截止。
## P2-02 JetBrains非商业开源许可/成熟OSS项目许可（B条件候选）
官方 https://www.jetbrains.com/community/opensource/ ；价值：符合条件的非商业OSS个人使用IDE免费；成熟项目可申请All Products Pack，非所有商业项目可用。预计10分钟核验：确认拟使用项目仓库开源许可证、是否非商业、是否有活跃维护者和社区影响；按官方两类方案核对后准备真实项目简介/仓库地址/贡献说明。若是FactoryOS商业工厂，不能将非商业许可直接用于商业交付；最终许可协议由用户确认。
## P2-03 GitHub Actions公共仓库免费分钟（B条件候选）
官方 https://github.com/pricing ；价值：公开OSS仓库CI执行分钟免费；预计5–10分钟只读核验。步骤：列出真正计划公开且已确认IP/许可的开源仓库→检查当前仓库Visibility和Billing/Actions分钟→仅设计CI，不自动公开代码或运行收费任务。若项目私有，按私有免费额度/超额规则单独评估，绝不为省成本直接转Public。
## P2-04 GitHub Copilot Pro热门OSS维护者福利（B条件候选）
官方 https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-teachers-and-os-maintainers ；价值：符合资格可免费Pro，需GitHub判定且每月重评。预计3分钟只读：用户本人打开Copilot设置检查是否显示eligible；无则不建议为申请而刷星/伪造维护记录。最终启用由用户确认。
