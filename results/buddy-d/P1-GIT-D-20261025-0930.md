## 分步推导

(1) 加速度定义：a = Δv/Δt（Δt→0），即速度变化量与发生这一变化所用时间之比；物理意义：描述速度变化快慢的物理量，是速度对时间的变化率，方向与 Δv 相同。
(2) 「另类加速度」A = (v_s−v₀)/s = Δv/Δs：速度变化量与对应位移之比，描述速度随位移变化的快慢（速度对位移的变化率）；A>0 表示加速，A<0 表示减速。
(3) A 恒定时 dv/ds = A，积分得 v(s) = v₀ + As，速度随位移线性变化。位移中点 s/2 处：v = v₀ + A·s/2 = v₀ + (v_s−v₀)/2 = (v₀+v_s)/2。

## 最终答案

(1)(2) 见推导 / (3) v = (v₀+v_s)/2
