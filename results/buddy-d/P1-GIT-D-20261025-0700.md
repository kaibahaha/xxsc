## 题目（第19题）

19. 几个水球可以挡住子弹？《国家地理频道》2019 年节目中实验证实：四个水球就足够！四个完全相同
的水球紧挨在一起水平排列，子弹在水球中沿水平方向做匀变速直线运动。恰好能穿出第四个水球，则可
以判定（            ）
A. 子弹在穿过每个水球前的速度比为 4∶3∶2∶1
B. 子弹穿过每个水球的时间比为 1∶2∶3∶4
C. 子弹穿出第三个水球的瞬时速度与全程的平均速度相等
D. 子弹在每个水球中平均速度相同

## 分步推导

子弹匀减速恰穿出第 4 个水球（末速 0），逆向 = 初速 0 的匀加速通过 4 个等厚（每段 d）水球。
1. 各段（正向）时间比 = 1:(√2−1):(√3−√2):(2−√3)，B 的 1:2:3:4 错误。
2. 穿各球前速度 ∝ √(剩余位移)：2:√3:√2:1，A 的 4:3:2:1 错误。
3. 全程时间 T = 2t₄（比例和），其中第 4 段 d = ½a t₄²；平均速度 = 4d/(2t₄) = √(2ad)；穿出第 3 球时仅剩最后一段 d，v = √(2ad)，两者相等——C 正确。
4. D：各段平均速度 = d/tᵢ 互不相同——错误。

## 最终答案

C
