## 题目（2025北京五十中高一10月月考物理 · 第2题）

如图所示，一小车从 A 点由静止开始做匀加速直线运动，若到达 B 点时速度为 v，到达 C 点时速度为 2v，则 x_AB : x_BC 等于（ ）

A. 1∶1　　B. 1∶2　　C. 1∶3　　D. 1∶4

## 分步推导

1. 小车由静止出发（v_A = 0）做匀加速直线运动，设加速度为 a。
2. 由匀变速直线运动的速度—位移关系 v² − v₀² = 2ax：
   - 对 A→B：v_B = v，故 x_AB = v² / (2a)。
   - 对 A→C：v_C = 2v，故 x_AC = (2v)² / (2a) = 4v² / (2a)。
3. B→C 段位移：x_BC = x_AC − x_AB = 4v²/(2a) − v²/(2a) = 3v²/(2a)。
4. 求比值：x_AB : x_BC = v²/(2a) : 3v²/(2a) = 1 : 3。

## 最终答案

C
