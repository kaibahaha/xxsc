## 题目（第19题）

几个水球可以挡住子弹？四个完全相同的水球紧挨在一起水平排列，子弹在水球中沿水平方向做匀变速直线运动。恰好能穿出第四个水球，则可以判定（ ）

A. 子弹在穿过每个水球前的速度比为 4∶3∶2∶1
B. 子弹穿过每个水球的时间比为 1∶2∶3∶4
C. 子弹穿出第三个水球的瞬时速度与全程的平均速度相等
D. 子弹在每个水球中平均速度相同

## 分步推导

设每个水球长度均为 L，子弹做匀减速直线运动、加速度大小为 a，进入第 1 个水球前速度为 v₀。"恰好穿出第 4 个水球"即到达第 4 个水球末端时速度恰为 0。

1. 采用逆向思维（从静止匀加速通过连续 4 段位移 L），由 v² = 2a·x 得：
   - v₀² = 2a·4L = 8aL（进入第1个前）
   - v₁² = 2a·3L = 6aL（进入第2个前）
   - v₂² = 2a·2L = 4aL（进入第3个前）
   - v₃² = 2a·L = 2aL（进入第4个前）
   故 v₀² : v₁² : v₂² : v₃² = 4 : 3 : 2 : 1，即"速度平方比"为 4:3:2:1；而速度本身之比 v₀ : v₁ : v₂ : v₃ = 2 : √3 : √2 : 1，并不等于 4:3:2:1。
   → A 把速度平方比误作速度比，**错误**。
2. 从静止匀加速通过连续相等位移 L 的时间比为 1 : (√2−1) : (√3−√2) : (2−√3)；正向穿过第 1~4 个水球的时间比为其逆序，不等于 1:2:3:4。→ B **错误**。
3. 穿出第 3 个水球时的速度即进入第 4 个水球前的速度 v₃。由 v₃² = v₀²/4 得 v₃ = v₀/2。
   全程为匀减速到 0，平均速度 = (v₀ + 0)/2 = v₀/2。
   两者相等。→ C **正确**。
4. 每个水球内位移相同（L），但所用时间不同，故各段平均速度不同。→ D **错误**。

## 最终答案

C
