## 题目（第2题）

2. 如图所示，一小车从 A 点由静止开始做匀加速直线运动，若到达 B 点时速度为 v，到达 C 点时速度为
2v，则 x AB : xBC 等于（   ）
A. 1∶1                B. 1∶2       C. 1∶3           D. 1∶4

## 分步推导

由 v² = 2ax（初速为零的匀加速）：xA ∝ v²。
1. x_AB 对应速度 0→v：x_AB ∝ v²。
2. x_BC 对应速度 v→2v：x_BC ∝ (2v)² − v² = 3v²。
3. 故 x_AB : x_BC = v² : 3v² = 1 : 3。
