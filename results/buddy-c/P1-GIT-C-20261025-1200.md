三、解答题

## 分步推导

(1) 打点计时器本身即计时仪器，还需测量点距的刻度尺——选 B（秒表、天平都不需要）。
(2) 甲图有振片、振针、复写纸，为电磁打点计时器，使用低压「交流 8V」电源；乙（墨粉纸盘、脉冲开关）为电火花计时器，用交流 220V。
(3) ① 应先接通电源、待打点稳定后再释放小车——选 B。
② 50 Hz 打点周期 0.02 s，相邻计数点间还有 4 个点未画出 → 计数点间隔 T = 5×0.02 = 0.1 s。
逐差法：a = [(s₄+s₅+s₆)−(s₁+s₂+s₃)]/(9T²) = [(5.97+6.78+7.64)−(3.59+4.41+5.19)]×10⁻² / (9×0.01) = 0.0720/0.09 = 0.80 m/s²。
v_B = (s₁+s₂)/(2T) = (3.59+4.41)×10⁻²/0.2 = 0.40 m/s。
(4) 电源实际 51 Hz：打点周期实际为 1/51 s < 1/50 s，计数点真实时间间隔小于 0.1 s；仍按 0.1 s 计算则分母偏大，测得速度偏小。

## 最终答案

B/甲/交流8V/B/0.1/0.80/0.40/偏小
