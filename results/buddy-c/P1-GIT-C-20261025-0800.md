## 题目（第13题）

急动度 J=Δa/Δt，运载工具加速度随时间变化如图直线所示，正确的是（ ）A. 做匀加速直线运动；B. t=t0 时急动度小于 t=2t0 时；C. 急动度描述速度变化快慢；D. 0~t0 时间速度变化量比 t0~2t0 时间速度变化量小

## 分步推导

a−t 为过原点直线，a=kt，急动度 J=Δa/Δt=斜率 k 为常数。A：a 随时间增大，非匀加速，错；B：J 为常数，t₀ 与 2t₀ 相等，错；C：急动度描述加速度变化快慢（非速度），错；D：0~t₀ 的 Δv=½·t₀·a(t₀)，t₀~2t₀ 的 Δv=½·(a(t₀)+a(2t₀))·t₀=½·(a₀+2a₀)·t₀，前者小于后者，D 对。

## 最终答案

D
