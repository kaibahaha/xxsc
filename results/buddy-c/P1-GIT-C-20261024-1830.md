## 题目（第10题）

图中甲、乙、丙是中学物理课本必修 1 中推导匀变速直线运动的位移公式所用的速度图像，下列说法正确的是（ ）

A. 这种用面积表示位移的方法只适用于匀变速直线运动
B. 甲图用矩形面积的和表示位移大小比丙图用梯形面积表示位移大小更接近真实值
C. 若丙图中纵坐标表示运动的加速度，则梯形面积表示加速度的变化量
D. 推导中把整个运动过程划分成很多小段，每一小段近似看作匀速直线运动，然后把各小段的位移相加，这里采用了微元法

## 分步推导

1. **面积法的普适性**：v-t 图线与时间轴围成的面积等于位移，这一结论对任意直线运动都成立（由 x = ∫v dt 直接得到），并非"只适用于匀变速直线运动"。→ **A 错误**。
2. **甲、乙、丙的近似程度**：课本推导中甲为较少矩形的粗近似，乙细分更多，丙为更精细的近似（或对应曲线/梯形下的真实面积）。细分越多、越接近真实面积，故丙比甲更接近真实值。B 说"甲比丙更接近真实值"与事实相反。→ **B 错误**。
3. **选项 C 的物理含义**：若纵坐标表示加速度（即 a-t 图像），则图线与时间轴围成的面积 = ∫a dt = Δv，表示**速度的变化量**，而非"加速度的变化量"（后者是加加速度/jerk）。→ **C 错误**。
4. **微元法**：把整个运动过程分成很多小段，每小段近似看作匀速直线运动，再把各小段位移相加再取极限——这正是**微元法（无限分割、以匀代变、求和取极限）**。→ **D 正确**。

## 最终答案

D
