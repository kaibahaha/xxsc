## FULL_QUESTION
几个水球可以挡住子弹？《国家地理频道》2019年节目中实验证实四个水球足够。四个完全相同的水球紧挨在一起水平排列，子弹在水球中沿水平方向做匀变速直线运动，恰好能穿出第四个水球，则可以判定（ ）。图示子弹由左向右依次穿过四个水球。A. 子弹在穿过每个水球前的速度比为4∶3∶2∶1；B. 子弹穿过每个水球的时间比为1∶2∶3∶4；C. 子弹穿出第三个水球的瞬时速度与全程的平均速度相等；D. 子弹在每个水球中平均速度相同。

## SOLUTION
设每球厚度L，子弹匀减速度大小b，恰穿出第四球时末速为0。全程4L满足v0²=2b·4L=8bL；穿出第三球后尚有一球厚L，v3²=2bL，故v3=v0/2。匀减速全程平均速度(v0+0)/2=v0/2，恰等于v3，C正确。速度按剩余距离平方根变化，并非A、B、D描述的规律。
