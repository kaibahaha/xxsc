一辆做匀减速直线运动的汽车，依次经过a、b、c三点。已知汽车在ab间与bc间的运动时间均为1s，ab段的平均速度是10m/s，bc段的平均速度是5m/s，则汽车做匀减速运动的加速度大小为（ ）。A. 2.5m/s²；B. 5m/s²；C. 7.5m/s²；D. 10m/s²。
