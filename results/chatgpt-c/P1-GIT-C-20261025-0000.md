## SOLUTION｜独立逐步推导

1. 设每球沿弹道的厚度L，子弹做匀减速直线运动，减速度大小a>0；恰好穿出第4球时末速度0。由v²=v0²-2ax，得v0²=2a×4L=8aL。
2. 穿出第三球时已运动3L，v3²=v0²-2a×3L=2aL，故v3=√(2aL)=v0/2。
3. 全程匀变速，平均速度v_avg=(v0+0)/2=v0/2，等于v3，C正确。
4. 各球入口速度比√4:√3:√2:1，不是4:3:2:1，排除A；匀减速下各球所用时间不呈1:2:3:4，排除B；各球平均速度逐球减小，排除D。
