## FULL_QUESTION
Q10. 图中甲、乙、丙是中学物理课本必修1中推导匀变速直线运动的位移公式所用的速度图像，下列说法正确的是（  ）。
图像：甲、乙均为速度随时间线性增大的v-t图，甲将时间划为较宽小段并以矩形面积求和，乙划为更细小段并以矩形面积求和；丙用直线下方的梯形面积表示位移。
A. 这种用面积表示位移的方法只适用于匀变速直线运动。
B. 甲图用矩形面积的和表示位移大小比丙图用梯形面积表示位移大小更接近真实值。
C. 若丙图中纵坐标表示运动的加速度，则梯形面积表示加速度的变化量。
D. 推导中把整个运动过程划分成很多小段，每一小段近似看作匀速直线运动，然后把各小段的位移相加，这里采用了微元法。

## SOLUTION
在v-t图上，极小时间段Δt内位移Δx≈v(t)Δt；将时间划为n段并求和，x≈Σv_iΔt_i。当分段长度趋于零时，得到积分x=∫v(t)dt，几何上是v-t曲线与时间轴围成的有向面积。这一方法对一般可积的速度函数均适用，故A错。对于匀变速直线运动，速度图像为直线，丙图的梯形面积直接等于真实位移，矩形近似不如梯形精确，故B错。若纵轴为加速度，面积∫a(t)dt表示速度变化量Δv，而非加速度变化量，故C错。把运动分割为微小时间元、近似求位移再累加取极限，正是微元法，故D正确。
