## FULL_QUESTION
4. 已知某物体做直线运动，其v−t图像如图所示，以下说法正确的是（ ）
A. 前8s内位移为0。
B. 前8s内位移为12m。
C. 前4s的位移为12m。
D. 0~4s内加速度方向与4s~8s内加速度方向相反。
原图：v(0)=+3m/s，v(4s)=0，v(8s)=−3m/s；0~8s为斜率恒定的下降直线。

## SOLUTION（独立推导）
1. 位移是v−t图线与时间轴之间的有向面积。0~4s为正三角形面积(1/2)×4×3=+6m。
2. 4~8s为负三角形面积−(1/2)×4×3=−6m，总位移0，因此A正确，B、C错误。
3. 整个0~8s斜率a=(−3−3)/8=−0.75m/s²不变，两个阶段加速度方向相同，D错误。

## FINAL_ANSWER
A
