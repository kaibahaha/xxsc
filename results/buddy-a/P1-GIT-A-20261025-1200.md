## 分步推导

急动度 J = Δa/Δt，a−t 图为过原点直线。
1. A：a 随时间增大，是变加速运动不是匀加速——错误。
2. B：J = 图线斜率，直线斜率恒定，t = t₀ 与 t = 2t₀ 时急动度相等——错误。
3. C：急动度描述加速度变化的快慢，不是速度变化快慢——错误。
4. D：a−t 图面积表示 Δv：0~t₀ 为小三角形，t₀~2t₀ 为梯形，故 0~t₀ 内速度变化量更小——正确。
