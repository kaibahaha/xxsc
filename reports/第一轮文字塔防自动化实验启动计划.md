# 第一轮文字塔防自动化实验启动计划

状态：BLOCKED，尚不满足完整无人值守启动门槛。
日期：2026-10-24。

## 实验目标

用一个正式授权的独立仓库，将已确认的文字塔防需求转成可部署网页版本；自动完成设计、编码、单元/浏览器测试、Pages 部署、线上验收、Drive 状态回写与证据归档。

## 启动前硬门槛

- [ ] 唯一需求源已指定：Drive 文档 ID、修订号、验收标准。
- [ ] 唯一实验仓库已指定或授权创建；生产分支保护已开启。
- [ ] Pages 已启用，试部署产生可匿名访问 URL。
- [ ] WorkBuddy MCP initialize、tools/list、真实推理均通过。
- [ ] WorkBuddy 使用的精确模型已安装/授权并返回可验证身份与 usage。
- [ ] 专用实验目录具有最小写权限；生产目录保持只读。
- [ ] GitHub/Drive 写操作采用幂等 key，失败可恢复。
- [ ] 线上 Playwright 测试和 artifact 保留策略已确定。

## 实验批次

1. **需求冻结**：读取 Drive 需求，记录文档 ID、revision、SHA-256 导出摘要；生成验收矩阵并回写待确认状态。
2. **隔离初始化**：创建实验分支，提交最小骨架；验证 branch protection 和 Actions 权限。
3. **设计与实现**：Codex 生成实现；WorkBuddy 作为独立复核/补充执行者，每次调用保存原始回执。
4. **测试门禁**：运行单元测试、Playwright 本地服务测试；任何失败自动归因、修复并有限重试。
5. **部署**：仅测试全绿后部署 Pages；记录 run、job、commit、deployment URL。
6. **线上验收**：Playwright 对公开 URL 执行核心流程；保留 report、trace、截图。
7. **交付回写**：向 Drive 回写 commit、run、deployment、测试计数、失败修复和证据链接；写后独立回读。
8. **收口**：生成 PASS/INTERFACE_ONLY/FAIL/UNAVAILABLE 表；任何阻断都停止晋级，不合并生产分支。

## 第一轮建议范围

只做一个可在 5 分钟内验收的最小纵切：

- 三条路线、三类敌人、两种塔；
- 一局 3 波；
- 资源消费、生命值、胜败状态；
- 刷新后可重新开始；
- 至少 2 个 Playwright 核心流程；
- Pages 线上 smoke；
- Drive 交付回写。

## 成功标准

- Actions 全绿且测试数、失败数明确；
- Pages URL 匿名可访问；
- 线上 Playwright 全绿；
- Codex 与 WorkBuddy 各有本轮真实调用回执；
- Drive 状态与 GitHub commit/run/deployment 一致且回读成功；
- 无生产分支、生产目录、既有定时任务变更。

## 当前启动判断
